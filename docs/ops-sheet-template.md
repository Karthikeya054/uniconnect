# Daily ops sheet — column template

The column layout operations teams fill in each day. No real data: this is
the header row plus a description of each column.

| Column | What goes in it |
|---|---|
| `Date` | YYYY-MM-DD |
| `University Name` | Exact university name (use consistent spelling) |
| `Sessions Planned` | Total teaching sessions scheduled for the day |
| `Sessions Completed` | Sessions actually conducted |
| `Sessions Cancelled` | Sessions that were cancelled |
| `Cancellation Reason` | Why cancelled (e.g. Holiday / Faculty unavailable / Technical issue) |
| `Enrolled` | Total students enrolled in active batches |
| `Attended` | Students who attended sessions today |
| `Coach Calls` | Coaching calls made by coaches today |
| `Parent Calls` | Calls made to parents today |
| `Instructors Total` | Total instructors assigned to this university |
| `Instructors On Leave` | Instructors on leave today |
| `Events Planned` | Events/workshops planned for the day |
| `Events Executed` | Events actually conducted |
| `Events Cancelled` | Events that were cancelled |
| `Exams Planned` | Exams/assessments scheduled |
| `Exams Completed` | Exams actually conducted |
| `Post Exam Comms Sent` | Post-exam result communications sent to students |
| `At Risk Total` | Students identified as at-risk of failing |
| `At Risk Informed` | At-risk students who were personally informed/counselled |
| `Acknowledgments` | Parent acknowledgment responses received |
| `Remarks` | Any additional notes or context for the day |
